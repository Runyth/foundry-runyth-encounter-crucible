# Rules data sources

The calculation engine contains numeric encounter-building tables and does not reproduce descriptive proprietary rules text.

References consulted during source reconstruction:

- Foundry VTT v13 API: https://foundryvtt.com/api/v13/
- Foundry module development: https://foundryvtt.com/article/module-development/
- D&D 2024 combat encounter budget table: https://roll20.net/compendium/dnd5e/Combat%20Encounters
- Foundry D&D 5e system source and structured Actor paths: https://github.com/foundryvtt/dnd5e

Before public publication, review the applicable SRD/Creative Commons attribution requirements and the repository owner's licensing choice.
